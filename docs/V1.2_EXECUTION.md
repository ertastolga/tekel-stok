   either finish and commit it, or `git stash push -m "v1.2 resume <date>"` and log that.
   Never discard work.
2. Verify the environment versions above and that `.venv` exists.
3. Run the default suite: `.venv\Scripts\python.exe -m pytest tests -q -p no:cacheprovider`
   and compare the passed count with the latest entry.
4. Read the plan, the traceability matrix and this log; continue at the first unchecked
   sub-step in the status table. No other state is required.
